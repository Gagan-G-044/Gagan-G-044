### `gagan@portfolio:~$ ls projects/`

📁 **[CoolRoute/](https://github.com/Gagan-G-044/temperature-based-optimal-path-finder-)** — Temperature-Aware Optimal Path Finder<br>
Routes perishable produce along cooler road corridors using road-temperature data and a heat-decay model, aimed at smallholder farm logistics in India. Built for ERROR 404 — Chapter 1 2K26 (project AI26AG02).<br>
`Node.js` `Express` `Leaflet.js` `OSRM` `Open-Meteo` `JavaScript`<br>
🔗 [Live demo](https://cool-route-y4w9.onrender.com/) · [Dashboard](https://cool-route-y4w9.onrender.com/dashboard.html) · [Source](https://github.com/Gagan-G-044/temperature-based-optimal-path-finder-)

📁 **[DefVoice/](https://github.com/Gagan-G-044/defvoice)** — AI Voice-Cloning Detection<br>
A research prototype that flags voice-cloning impersonation on live VoIP calls placed inside its own app, using a laptop as a middlebox that analyzes short audio windows and sends risk levels to a phone and a web dashboard.<br>
`Python` `FastAPI` `aiortc (WebRTC)` `PyTorch` `Flutter`<br>
⚠️ Scope: works only on calls made inside the DefVoice app. It does not detect ordinary cellular or WhatsApp calls.<br>
🔗 [Source](https://github.com/Gagan-G-044/defvoice) · _No public live demo._

📁 **[Lumen-AI/](https://github.com/Gagan-G-044/chatbot-lumen-ai)** — Conversational AI Chatbot<br>
A chatbot with real-time responses, dark mode, Markdown-rendered answers, a model-fallback system, and rate limiting.<br>
`Python` `Flask` `Google Gemini API` `HTML/CSS/JS` `Render`<br>
🔗 [Live demo](https://chatbot-lumenai.onrender.com/) · [Source](https://github.com/Gagan-G-044/chatbot-lumen-ai)

📁 **[Study-Helper/](https://github.com/Gagan-G-044/study-helper-)** — AI-Powered Study Assistance<br>
Turns unstructured notes into structured revision guides, glossaries, and practice Q&A, with a server-side proxy that keeps the API key out of the browser.<br>
`React 19` `Vite` `Tailwind CSS` `TypeScript` `Express` `Google Gemini API` `Render`<br>
🔗 [Live demo](https://study-helper-qhyx.onrender.com/) · [Source](https://github.com/Gagan-G-044/study-helper-)
